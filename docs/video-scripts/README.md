## Production Notes

### Tools
- **Screen Studio** - Cinematic screen recordings
- **Descript** - Edit video like a document
- **Uppbeat.io** - Royalty-free music

### Style Guidelines
- Fast cuts, no dead air
- Zoom on important UI elements
- Use motion to guide attention
- Upbeat background music (lower volume during VO)
- Captions always on (many watch muted)

### Brand Voice
- Confident but not corporate
- Quick and direct
- Focus on outcomes, not features
