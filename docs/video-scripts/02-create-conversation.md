## Production Notes

- Use Screen Studio's auto-zoom on clicks
- Smooth cursor movements (Screen Studio handles this)
- Speed up typing sequences slightly
- Add subtle sound effects on button clicks
- Ensure all text is readable (zoom if needed)

## Key Moments to Emphasize

1. **AI suggestions** - This is a differentiator, give it a moment
2. **Privacy options** - Quick but visible, builds trust
3. **Share link** - The payoff, make it feel satisfying
